# sangthai.dev

The source of my personal site, served by GitHub Pages from this repository at
[sangthai.dev](https://sangthai.dev). It is a single hand-written
`index.html` — no build step, no framework, no dependencies to install. Open it
in a browser and you are looking at the site.

```
index.html     the whole site: markup, styles and scripts in one file
images/        project screenshots
favicon.svg    site icon
CNAME          the custom domain GitHub Pages serves from
sitemap.xml    submitted to search engines
robots.txt
```
